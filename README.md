# MANU Launcher — Masterstrap-style

Full-featured Roblox FastFlag + system optimizer for Android.

## Features
- FastFlag editor & presets
- Graphics / performance toggles (FPS, MSAA, FRM, SkyGray, NO VFX…)
- Game Mode: Turbo, RAM clean, screen on, DND, kill background (Shizuku)
- Root + Shizuku support (reflection-safe)
- Dual write path for ClientAppSettings.json
- GitHub Actions → APK

## Build
Push → Actions → download `manu-launcher-apk`
